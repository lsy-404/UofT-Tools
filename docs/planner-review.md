## Confirmed findings before repair

1. **Incomplete program catalogs.** `scripts/planner/scrape_campus_catalogs.py` hard-codes three subjects per new campus. Current snapshots contain 11 Arts & Science programs and 23 UTSC programs; UTM contains 212. New course metadata is also limited to codes mentioned by those selected programs. There is no reconciliation against the complete official directory or pagination-completeness test.
2. **Sources are official but collection is incomplete.** Program prose currently comes from `/section/...` pages (UTSC) and linked `/program/...` pages (Arts & Science); descriptions, prerequisites and exclusions come from `/course/...`. Scheduled sections and times come separately from the official Timetable Builder API. The appropriate discovery inventories are [UTSC Program Search](https://utsc.calendar.utoronto.ca/search-programs) and [Arts & Science Program and Certificate Search](https://artsci.calendar.utoronto.ca/search-programs), plus the separate UTSG faculty calendars.
3. **Course level is mislabeled as study year.** The reported course is `COPB50H3`. `levelOf` maps B to 2, `courseYear` forwards it and `CourseListView` renders `Y2`. The [official course page](https://utsc.calendar.utoronto.ca/course/copb50h3) explicitly recommends completing it in the first year. Store course level, official recommended timing and enrolment restrictions separately; do not convert a code level into an eligibility year.
4. **Required courses, alternatives, elective pools and recommendations are flattened.** The importer unions every code in enrolment and completion prose into `program.courses`. The UI labels them all “Required by”. For UTSC CS Major `SCMAJ1688`, this includes the optional writing recommendation list. It also flattens the MATB24H3/STAB52H3 alternative, and cannot enumerate the open “1.0 credits in any C- or D-level CSC courses” pool because that clause has no complete course codes. Preserve nested requirement structure and its source; distinguish mandatory individual courses, choose-one alternatives, credit/count pools, admission requirements, recommendations and notes. A course's role belongs to a program requirement, not globally to that course.
5. **Text-only restrictions disappear.** COPB50H3 has a stored prerequisite text restricting enrolment to Arts & Science Co-op, but an empty `prereqs` code array. `prereqInfo` returns “none” before considering the text. Display non-course restrictions and never infer enrolment eligibility from course codes alone.
6. **Co-op academic credit is overstated.** Reproducing `progress('utsc', {COPB50H3: 3}, courses, [3])` returns 0.5 total credit. The [official co-op rules](https://utsc.calendar.utoronto.ca/co-operative-programs) state that work-term preparation courses confer no academic credit, and work terms carry 0.0 credits. Academic credit must not be inferred solely from H/Y for these courses. Keep co-op completion tracking separate from degree credit.
